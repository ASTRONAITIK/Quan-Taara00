About this Interface

Quan-Taara Interface Mark-I is an interactive physics and astrophysics compendium. The background renders a live black hole simulation with Keplerian disk rotation and relativistic jets. The Earth Observatory pulls live global events from NASA EONET and real-time weather from Open-Meteo — both free, no API key required. ASTROPIX AI answers common physics and space questions locally, with optional Ollama or Groq support for deeper responses.
