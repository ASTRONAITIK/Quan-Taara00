# Quan-Taara

Quan-Taara is a physics and space observatory with an interactive astronomy interface, an ASTROPIX local physics guide, and a separate space-news page.

## Open the site

Keep `quantaaraPrototype.backup.html` and `news.html` in the same folder. Open `quantaaraPrototype.backup.html` in a web browser, then choose **Space News** in the header to open the separate news page. The news page retrieves recent headlines directly from The Space Devs Spaceflight News API and displays stories published during the previous 24 hours; an internet connection is needed for live headlines.

The pages are standalone HTML. ASTROPIX currently uses its built-in local physics guide; a broader AI model can be connected later.
